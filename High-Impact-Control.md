# High Impact Control – UI Policy

- **Table:** Incident
- **Condition:** Impact is `1 - High`
- **Active:** True
- **Reverse if false:** True

## UI Policy Action
- **Field:** Assignment group
- **Mandatory:** True

## Urgency Action
- **Field:** Urgency
- **Read-only:** True

When the Impact condition is no longer true, the policy changes are reversed.
